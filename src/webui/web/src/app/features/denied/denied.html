How access works here

Admins manage the allowlist from Admin → Users. Seeded admins — the logins listed in WEBUI_ADMIN_LOGINS when this app started — can never be removed or demoted; that's the lockout guard that keeps at least one admin always able to fix the list. There is deliberately no read-only role: anyone who can open a terminal here can already do anything, so a read-only tier would be security theatre.

Ask an admin to add your login to the allowlist, then reload this page.
